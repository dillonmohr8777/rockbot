# Rockbot command center

## Mode

Operate. This is a high-frequency local work surface, not a marketing page.

## Job

Let Dillon choose any authenticated or local model, route a task through the smallest useful operating team, watch normalized evidence stream in, and distinguish complete, partial, blocked, drafted, and approval-gated outcomes without leaving the console.

## Visual authority

- Preserve the installed Grok Bot shell topology: light two-pane frame, dense left bot rail, one dominant conversation, fixed bottom composer, and a model control anchored at the sidebar bottom.
- Translate Protocol 54 semantics into the shell: cobalt for active work, green for verified evidence, amber for approval boundaries, and red only for stopped or unavailable states.
- Use the recorded Rockbot agent colors and geometric bot marks as identity, never borrowed brand artwork.

## Proof sequence

1. The selected operating agent and authority are visible before the task begins.
2. The user can find all 22 recorded team definitions without losing the main thread.
3. The model switch exposes live readiness and available models at the bottom of the sidebar.
4. The run visibly resolves a route, caps specialists at three, streams their evidence, and fans in through Marketing Chief.
5. Every completed run ends with a redacted receipt and explicit external-action state.
6. Routines and recorded schedule templates are searchable but never presented as current live scheduler state.

## Responsive behavior

Desktop keeps the two-pane shell and a scroll-contained sidebar. Mobile turns the sidebar and inspector into dismissible off-canvas surfaces while keeping the composer and authority visible. No horizontal page overflow is acceptable at either breakpoint.

## Interaction and accessibility

Keyboard focus is visible. Ctrl or Command plus K focuses the composer. Escape closes model, sidebar, and inspector surfaces. Enter submits and Shift plus Enter adds a line. Reduced motion removes the reveal and streaming movement without hiding state.

## Non-negotiable boundaries

Default authority is Observe. Workspace is a per-run explicit choice. External sending, publishing, deployment, spending, account changes, destructive actions, and canonical queue mutation are denied. Provider and schedule labels must reflect current local truth or clearly say recorded template.
